# K.Y.L. — Know Your LLM 🤖

As GenAI fills the web, knowing which model wrote a given passage is becoming critical for auditing synthetic data — a task known as `authorship attribution`.
Standard AI detectors only try to distinguish machine-written text from human writing. However, each major LLM leaves behind subtle stylistic fingerprints in vocabulary, phrasing, and punctuation, shaped by the distinct training pipelines and post-training choices adopted by major labs.

**🎯 PROBLEM STATEMENT:** In this Kaggle-hosted competition, the goal is to identify which frontier language model (OpenAI, Google, Anthropic, Qwen, etc.) generated a given passage, using nothing but the LLM-generated text itself.
